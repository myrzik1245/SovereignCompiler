# 🇷🇺 SovereignCompiler (Суверенный Компилятор)

**SovereignCompiler** — это учебный компилятор с собственной лексической и синтаксической базой, написанный на **C#** (.NET). Его главная особенность — уникальный и колоритный синтаксис на базе русской терминологии, адаптированный под строгие стандарты процедурного программирования.

---

## 🚀 Особенности синтаксиса (CZ)

Язык компилятора сочетает в себе строгую типизацию, ссылки, классические управляющие конструкции и бюрократический аппарат (switch-case), переосмысленные на отечественный лад:

* **Импорт библиотек:** `#наш_аналог "стандартная_библиотека"`
* **Типы данных:** `целое` (int), `дробное` (float), `текстовое` (string), `логическое` (bool), `пусто` (void).
* **Условные ветвления:** `если_надо (...) { ... } а_придется { ... }`
* **Циклы:** `пока_надо (...) { ... }`
* **Выход/Прерывание:** `отбой` (break)
* **Возврат значения:** `славу_отдать` (return)
* **Переключатели (Switch):** `бюрократический_аппарат` с блоками `инстанция N: { ... }`

---

## 📄 Пример кода на CZ

Вот так выглядит стандартная программа, проверяющая возраст и уровень доступа:

```cz
#наш_аналог "стандартная_библиотека"

целое проверить_уровень(целое &уровень) {
    если_надо (уровень >= 18) {
        славу_отдать 1;
    }
    а_придется {
        славу_отдать 0;
    }
}

пусто главная_скрепа() {
    целое возраст = 25;
    целое &ссылка_на_возраст = возраст;
    текстовое приветствие = "Здравствуйте, товарищ!";
    логическое допуск = правда;
    дробное коэффициент = 1.8;

    если_надо (ссылка_на_возраст >= 18) {
        рапорт(приветствие);
    }
    а_придется {
        отбой;
    }

    целое счетчик = 0;
    пока_надо (счетчик < 3) {
        рапорт("Итерация цикла...");
        счетчик = счетчик + 1;
    }

    целое инстанция_номер = 2;
    бюрократический_аппарат (инстанция_номер) {
        инстанция 1: {
            рапорт("Первая инстанция: отказ");
            отбой;
        }
        инстанция 2: {
            рапорт("Вторая инстанция: документы согласованы");
            отбой;
        }
    }
}
